Oggleflint and Bazzalan have no listed verified drops; absence from the guide is not proof of no loot.

Addon 0.3.0 has quest/session captures but no PvE kill/loot/clear collector. Current website already validates optional pveHistory and progress records. Keep event IDs stable and use verified game IDs, run/session identity, character identity, explicit timestamps and collection source. Kill/clear/loot events must be separate: item possession is not a kill and checking every listed boss is not a full clear. Lockout expiry/difficulty observations need a separately designed additive contract after real API validation. Existing quest, character, inventory, raw payload, import version, cloud envelopes and privacy behavior must remain compatible.

Recommended next milestone: validate and extend ForeverArmory's instance observation collector in the actual client, then use sanitized evidence to improve this catalog.
